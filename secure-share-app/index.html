How It Works

Threat Model

  • The browser derives an AES-GCM key from your passphrase with PBKDF2.
  • The server receives only encrypted bytes plus decryption metadata.
  • Links expire automatically and can be limited to a set number of downloads.
  • You must share the passphrase out-of-band for the recipient to decrypt.
