# PhishSense Trainer

A lightweight phishing detection trainer you can run locally without any build tooling.

## Features

- Simulated email and SMS phishing scenarios
- Immediate explanations after each answer
- Score tracking across a training round
- A simple "focus areas" panel that highlights common missed categories

## Run

Open `index.html` in a browser.
